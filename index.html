Start reviewing

  1. Open HTML Review. It connects to the hosted review server by default.
  2. Sign in with your display name and the reviewer access code from your administrator.
  3. Enter an authorized website URL and click Open page.
  4. Click Start selecting, select an element, write your feedback, and save.

Public downloads do not grant access to review data. Ask your administrator for an access code and authorized website hostnames.

Before you launch

macOS packages are ad-hoc signed and not notarized. Windows packages have no publisher certificate. Your operating system may show a security prompt.

Both Mac packages passed desktop integration checks; Intel was tested through Rosetta. Windows and Linux builds have not been run on their native operating systems.

The app needs a connection to the review server. Node.js and npm are not required. To use another server, follow the server connection instructions.
